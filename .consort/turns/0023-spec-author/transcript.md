## Final reasoning

I wrote S3-sku-detail-view's four acceptance criteria and added two S3 open questions to `feature-spec.md`. The S3 self-check passed.

The registration requires AC4 (empty state for a SKU with no stock), but the feature request never asks for it. I wrote it to match the registration.

The two open questions, each with my recommended answer:
- **Reaching a SKU with no stock:** if SKUs only exist through their stock records, it's unclear how the operator lands on one with none. I recommend that opening that SKU's detail directly shows the AC4 empty state, not a not-found error.
- **Par level:** F1 has no way to record it, so I recommend always showing "not tracked" and leaving capture to a later feature.
